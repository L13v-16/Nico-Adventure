# Arte v99

Quatro atlas gerados com image_gen integrado a partir das referências do jogo. PNGs preservados sem edição raster. Recortes, enquadramento e animações definidos no Godot em polish99_art.gd. Prompts, fontes e SHA-256 em prompts.json.

Recortes opacos conectados medidos sem modificar as imagens: atlases.tres. Canvas comum por folha, ancoragem dos pés por quadro; transparência filtrada no shader nativo.
