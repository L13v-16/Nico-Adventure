# Plataformas do Submundo — v94

Seis sprites gerados com image_gen, usando o terreno V39 e a referência de Nico V46. PNG original com alpha preservado, sem edição de pixels. `prompt.txt` contém o prompt completo e `source.json` registra origem, SHA-256 e os recortes nativos.

AtlasTexture recorta cada silhueta inteira com margem transparente. `walk_top` alinha o topo útil ao colisor. Rochas gravitacionais mantêm proporção; lajes usam extremidades proporcionais e centro repetido para evitar achatamento. O shader recorta resíduos de alpha abaixo de 0,94. Cristais ciano, roxo e âmbar continuam identificando seguir, afastar e patrulhar.
